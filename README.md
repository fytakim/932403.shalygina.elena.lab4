## Описание работы

В проекте реализованы следующие элементы согласно техническому заданию:
* Страница из лабораторной №3 дополнена внешним скриптом `script.js`, подключённым с атрибутом `defer`.
* В разделе «Фотопроекты» добавлена кнопка «Проанализировать количество фото», по клику на которую запускается анализ.
* Создан массив из 7 чисел с количеством сделанных фото за день.
* Ввод имени пользователя реализован через `prompt` с запасным значением «Гость».
* Функция `findMax` находит максимальное количество фото за день.
* Функция `filterHighActivityDays` оставляет только дни с количеством фото более 200.
* Функция `calculateSum` считает общее количество фото.
* С помощью цикла подсчитаны дни с малым количеством фото (не более 50) и их процент от всех дней.
* Через `alert` выводится приветствие с именем и сообщение «Всего сделано X фото, в Y днях активность была высокой».
* В консоль (`console.log`) выводятся процент и количество дней с малой активностью.
* Добавлено дополнительное условие: если максимум больше 300, в консоль выводится «В этот день вы были особенно продуктивны!».

Код проверен в консоли разработчика браузера.
